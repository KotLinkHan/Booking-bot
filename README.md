# Booking Bot

Telegram-бот для онлайн-запису клієнтів (барбершоп, салон, репетитор).

## Можливості
- Запис за кроками: послуга → дата → час → підтвердження
- Зайняті години автоматично приховуються, подвійний запис неможливий
- Миттєве сповіщення майстру про новий запис
- Автоматичні нагадування клієнтам за 2 години до візиту
- Команда /today для майстра: розклад на день

## Стек
Python 3.13, aiogram 3, SQLAlchemy 2 (async), PostgreSQL

## Запуск
1. `git clone ...` і `pip install -r requirements.txt`
2. Створи базу в PostgreSQL
3. Скопіюй `.env.example` у `.env` і заповни значення
4. `python main.py`
